## 1. 한 문장

## 2. 현재 상태
| 항목 | 값 | 날짜 |
|---|---|---|
| 진행 주차 | 0 / 12 | 2026-10-10 |
| 누적 학습일 | 0 | 2026-10-10 |

공부 저장소라 evals 점수 대신 진행도를 적는다. 평가(evals)는 7주차부터 `evals/`에 쌓는다.

## 3. 실패 로그 요약
아직 없음. 막히거나 틀린 것은 [`docs/failures.md`](docs/failures.md)에 기록한다.

## 4. 자율성 표
| 작업 | 방식 | 이유 |
|---|---|---|
| 학습 계획 초안 | AI 제안 → 내가 확인 | 내 실력·일정은 내가 제일 잘 안다 |
| 연습 코드 | 내가 직접 작성 | 손으로 쳐야 배운다 |
| 코드 리뷰·설명 | AI 제안 | 틀린 설명이 있을 수 있어 직접 실행해 확인 |
| 시장 수치 | 원 출처 확인 후 사용 | AI 요약은 틀릴 수 있다 |
